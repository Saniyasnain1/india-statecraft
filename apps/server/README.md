# India: Statecraft — Server Package (Reserved)

This directory is reserved for future authoritative multiplayer services and backend APIs.

## Planned Technology:
- **Cloudflare Workers**: High-performance, low-latency edge REST & WebSocket endpoints.
- **Cloudflare Durable Objects**: Authoritative game session rooms for multiplayer state synchronization and anti-cheat arbitration.
- **Supabase PostgreSQL**: Persistent user profiles, global leaderboards, and cloud save synchronization.

*Note: In the current single-player release, all simulation logic executes locally within a browser Web Worker.*
